# Wayfarer 弾性腱マップ モック v0.2.2

万博レガシーマップ Ver 2.0 向けの、訪問済みスポットを「メタボール＋弾性腱」で結ぶ操作モックです。

## このモックで確認できること

- 指定した3地点を訪問順 `1 → 2 → 3` で接続
- 赤ピンの頭部同士を、中央ほど細い赤い弾性腱で接続
- レイヤー順を `青丸 → 白丸 → 赤ピン → 弾性腱 → 地図` に固定
- 弾性腱の中央幅を `3〜14px` でリアルタイム調整
- 揺れの停止・再開
- 接続の伸長アニメーション再生
- 地図のパン／ズーム後もピンと弾性腱を再投影

## 必要なもの

- Node.js 22.13.0 以上
- インターネット接続（地図タイルの読み込みに使用）

## 起動方法

ZIPを展開し、`START_APP.bat` をダブルクリックしてください。

- 初回だけ必要なパッケージを自動的にインストールします。
- `pnpm` が未導入の場合は、Node.js付属の `npx` または `npm` を自動利用します。
- インストール後、ローカルサーバーを起動してブラウザーを開きます。
- アプリを終了するときは、黒い起動ウィンドウを閉じるか `Ctrl+C` を押します。

`pnpm install` は起動ファイル名ではなく、パッケージを準備するためのコマンドです。手動で起動する場合だけ、ターミナルで次を実行します。

```powershell
pnpm install
pnpm dev
```

表示されたURL（通常は `http://localhost:3000/`）をブラウザーで開いてください。

## 製品ビルドの確認

```powershell
pnpm build
```

## 主な構成

- `app/elastic-map.tsx` — Leaflet、Paper.js、ピン、弾性腱、操作UI
- `app/page.tsx` — 画面の入口
- `app/globals.css` — 共通スタイル
- `public/myakupin_red.webp` — 赤ピン画像

## 注意

- これは検証用のソースコード一式です。Windows用の単体実行ファイル（`.exe`）ではありません。
- Windows Defenderの確認が出た場合、外部公開は不要なのでパブリックネットワークを許可する必要はありません。
- 地図はCARTO／OpenStreetMap系タイルをオンライン取得します。完全オフライン化には、別途オフライン用タイルの同梱またはローカル配信が必要です。
- 実運用では地点数増加時の差分更新、低FPSモード、タイル利用規約・帰属表示の確認を行ってください。
